# Product

## Register

product

## Users

Frameforge is a private local tool for a game developer building character concepts and production references. The user works iteratively: they begin with one source image, generate controlled variations and orthographic views, compare results, and prepare image sets for later game-art work.

## Product Purpose

Frameforge reduces the manual work around image-generation sessions. It combines a visual graph, durable local projects, a generation queue, and an asset library so useful results remain organized and reusable. Success means the developer can move from one reference to a consistent set of outputs without cloud project management, API billing surprises, or repeated file housekeeping.

## Brand Personality

Technical, focused, dependable. The interface should feel like a compact production instrument: direct controls, clear state, restrained visual feedback, and no promotional tone.

## Anti-references

- A generic cloud SaaS dashboard with pricing, collaboration, or account-management surfaces.
- A decorative node editor where connections look impressive but routine asset work remains manual.
- A modal-heavy image browser that hides context and interrupts iteration.
- Provider controls that silently fall back, imply unsupported access, or obscure quota usage.
- An overloaded creative suite that exposes advanced controls before the underlying provider supports them.

## Design Principles

1. Keep the current asset and graph context visible while tools open alongside it.
2. Make destructive actions recoverable first and explicit when permanent.
3. Treat generated images as durable local assets with searchable provenance.
4. Show provider capability and job state truthfully at the point of action.
5. Prefer one compound workflow node over repeated boilerplate branches when outputs share one intent.

## Accessibility & Inclusion

Target WCAG 2.1 AA for text contrast and keyboard operation. Do not communicate state by color alone. Preserve visible focus, descriptive labels, reduced-motion behavior, and structural mobile layouts that keep the canvas usable.
